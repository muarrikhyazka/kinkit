# Kinkit brand

Single source of truth for the logo. Every surface (web, phone app, TV apps, landing page) must use
these files or exact renders of them. Change the logo here first, then re-export everywhere.

- `kinkit-logo.svg` – app icon: purple tile (gradient #6366F1 → #4F46E5, 16/64 corner radius),
  white house outline with a white dot.
- `kinkit-mark.svg` – the white house mark alone (for use on a purple background, e.g. Android
  adaptive-icon foreground or next to the wordmark).
- Colours: purple #4F46E5 (primary), #6366F1 (gradient top), white #FFFFFF.
